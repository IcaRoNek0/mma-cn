Validation checks whether each location still has valid Street View coverage and classifies any problems. Run it via **Validate locations** in the command palette (a bulk operation with a scope).

## What to report

Before it runs, validation asks which groups you want back. Each group you tick becomes its own selection, and a location can land in several. The groups that match the original categories are ticked by default.

The **default pano** is the one a location's coordinates load when it is not pinned.

- **Valid location.** Nothing to report.
- **Newer coverage available.** A pinned location, and official coverage newer than its pano exists.
- **Coverage updated since last view.** An unpinned location whose stored pano is older than coverage now available.
- **Not found.** No coverage at the coordinates or pano ID.
- **Pano ID broke.** The pinned pano ID no longer resolves.
- **Unofficial.** Resolves to user-uploaded coverage.
- **Badcam, but good coverage available.** The current coverage is a low-quality camera, but a better one exists in the timeline.

Off by default:

- **Newer coverage than the stored pano.** Either of the two newer-coverage groups, pinned or not.
- **Pinned away from the default pano.** The location is pinned to a pano other than the default.
- **Default pano is not the newest.** The default pano has newer captures in its own timeline, so loading the coordinates shows older coverage.

Results become **Validation** selections you can act on, for example review every "Pano ID broke" location and re-pin it.
